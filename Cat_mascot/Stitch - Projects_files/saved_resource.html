Anvaya

Anvaya is a real-time assistive tool that bridges communication barriers by converting hand gestures and sign language into spoken words. The system captures video frames via a web interface, processes hand landmarks and gestures using a computer vision pipeline, predicts the corresponding signs, converts them to text, and synthesizes speech output in real time.

📌 Features

  • Real-Time Landmark Detection: Captures hand gestures frame-by-frame using a web camera feed.

  • Gesture Classification: Custom machine learning model trained to classify gestures and sign language alphabets/words.

  • Text & Speech Generation: Instantly converts recognized gestures into readable text and natural audio speech (TTS).

  • Web-Based UI: Lightweight, responsive interface for video input capture and output display.

🛠️ System Architecture

  1. Input: Web camera captures real-time video frames via the web interface.

  2. Preprocessing & Feature Extraction: OpenCV and MediaPipe extract key 2D/3D hand coordinates and landmark vectors.

  3. Inference: A trained deep learning model evaluates the coordinate sequence/frame to predict the gesture.

  4. Text-to-Speech (TTS): The recognized gesture string is buffered into sentences and synthesized into spoken audio.

1. Executive Summary & Vision

Project Anvaya is a real-time assistive translation platform engineered to bridge communication gaps for individuals who communicate via sign language and hand gestures.

By unifying low-latency hand landmark detection (via MediaPipe/OpenCV), custom deep-learning gesture classification, and instant natural language text-to-speech (TTS) synthesis, Anvaya empowers users with fluid, expressive two-way communication in daily conversations, educational environments, and professional settings.

Core Value Proposition

  • Frictionless Accessibility: Zero specialized hardware required—runs natively on commodity webcams and smartphone cameras.

  • Empathetic & Approachable: Warm, friendly UI featuring playful hand-drawn doodle mascots to reduce clinical intimidation.

  • Privacy First: Client-side landmark extraction minimizes raw video transmission and honors user privacy.

2. Problem Statement & User Personas

2.1 The Problem

Over 70 million deaf and hard-of-hearing individuals worldwide use sign language as their primary mode of expression. Mainstream digital tools lack intuitive, bidirectional gesture-to-voice interfaces, leaving non-signing communication partners unable to understand signs in spontaneous, real-time contexts.

3. Product Scope & Functional Requirements

3.1 Live Gesture Capture & Landmark Tracking (Module 1)

  • FR-1.1 Video Capture Stream: Ingest live 720p/1080p webcam input at $\ge$ 30 FPS with hardware acceleration.

  • FR-1.2 Landmark Extraction: Real-time extraction of 21 3D hand landmarks per hand via MediaPipe Hands pipeline.

  • FR-1.3 Viewport HUD: High-contrast wireframe overlay displaying detected skeletal coordinates and bounding boxes.

  • FR-1.4 Stream Controls: Immediate camera enable/disable toggle, camera selector (front/back), and latency diagnostics.

3.2 Machine Learning Inference & Sentence Buffering (Module 2)

  • FR-2.1 Gesture Classification: Continuous sequence evaluation classifying static alphabet signs and dynamic multi-frame gesture vocabularies.

  • FR-2.2 Grammar & Sentence Engine: Token smoothing and predictive buffering to assemble isolated signs into grammatically fluent text rather than literal letter-by-letter strings.

  • FR-2.3 Mascot Feedback Loop: Dynamic state visualization (Idle, Detecting, Translating) featuring animated doodle companion "Anvaya Robot" to provide reassuring visual cues.

3.3 Text-to-Speech (TTS) & Audio Controls (Module 3)

  • FR-3.1 Real-Time Audio Playback: Instant speech synthesis triggered automatically or on user demand ("Speak Sentence").

  • FR-3.2 Voice Customization:

    • Speech playback rate / speed slider ($0.5\times$ to $2.0\times$).

    • Pitch modulation slider ($0.5\times$ to $1.5\times$).

    • Voice accent & locale selector (e.g., Neutral US, Warm UK, ES, IN).

  • FR-3.3 Clipboard & Text Operations: 1-click clipboard copy, manual inline sentence editing, and clear buffer action.

3.4 History & Session Logging (Module 4)

  • FR-4.1 Session Transcript: Collapsible chronological log recording timestamped gesture inputs and corresponding translated text.

  • FR-4.2 Export Capabilities: Ability to export transcripts to plain text or Markdown for records and consultation notes.

6. Success Metrics & KPIs

  1. Inference Latency: $< 120\text{ ms}$ round-trip from video capture frame to screen text display.

  2. Classification Accuracy: $> 96.5$ Top-1 accuracy across standard sign alphabet and core conversational vocabulary.

  3. TTS Initiation Time: $< 250\text{ ms}$ upon sentence completion trigger.

  4. User Accessibility Score: $100$ WCAG 2.1 AA compliance across contrast ratios and screen-reader accessibility.

  5. Session Completion Rate: $> 92$ of initiation sessions result in successfully verbalized conversational exchanges.

7. Roadmap & Phased Delivery

  • Phase 1 (Current): Single-page web experience with hero story, live landmark HUD mock/integration, live translation box, and custom TTS controls.

  • Phase 2 (Q2 2025): Full WebSocket integration with gesture_model.h5, dynamic 2-way conversation mode (Speech-to-Text reverse translation for signing users).

  • Phase 3 (Q3 2025): Mobile native apps (iOS / Android) with offline on-device neural engine inference and custom community gesture recording library.
